# AI Connect Hub

Make me a ai api connector agent routing MCP agent that calls lovable ai api safely and support use of the ai into different projects without any auth. 







 AI Connector Hub end to end: a landing page, docs, an console (projects, key issuing with allowlist/rate-limit/token-cap, playground, usage logs), the `POST /api/public/v1/chat` gateway that auto-routes by task with fallbacks, and an OAuth-protected MCP server at `/mcp` with 4 tools — key secrets are hashed and shown once, and Lovable AI credentials never leave the server

This project was built with [Lovable](https://lovable.dev).
